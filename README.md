# Trisagio Shorts — sitio web oficial

Sitio estático de [Trisagio Shorts](https://trisagioshorts.github.io/), publicado con GitHub Pages.

- Sin dependencias, sin cookies ni analítica.
- `index.html`: inicio · `contacto.html`: contacto · `privacidad.html` y `terminos.html`: páginas legales.
- `styles.css` y `main.js`: estilos y script mínimo (menú móvil, animaciones, fondo de estrellas).

Este repositorio no contiene credenciales ni código de la aplicación interna de automatización.
